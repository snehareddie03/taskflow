# TaskFlow

TaskFlow is a Task Management Web Application built using Next.js, TypeScript, Prisma, Supabase PostgreSQL, and Tailwind CSS.

## Features

- Create Task
- Edit Task
- Delete Task
- Complete Task
- Search Tasks
- Filter Tasks
- Responsive UI
- Prisma ORM
- Supabase PostgreSQL Database

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- Supabase PostgreSQL

## Installation

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
DATABASE_URL=your_database_url
```

## Run Project

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
